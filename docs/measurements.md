# Wait times

Loading the Imre model takes approx 800 ms on a pixel 6a. (very decent if you ask me)
Loading system TTS is 33ms.
Synthesizing a short phrase with Imre ("Voltatok a boltban?) takes around 120-140ms, very comfortable.
Synthesizing with the system TTS is fast 14 ms for ("Voltál már fürdeni? Én most megyek majd.") appears faster than Imre.

# Tuning

I can't hear any difference when moving the noise sliders, so default should be okay for both.
The default length param produces too fast speech, a setting of 1.2 sounds a lot more natural and understandable.

# Imre vs System TTS

Length 1.2 for Imre produces about the same speed as the system TTS. Seems ok.
